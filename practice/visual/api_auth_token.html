Как токен попадает в каждый запрос

Стенд «мини-биржа», реальные ответы. Сервер не помнит тебя между запросами: доказательство «это я» (токен) должно ехать в заголовке каждого запроса. Сессия кладёт его туда сама.

Запомни три вопроса про авторизацию
  1. Откуда токен? Из ответа POST /auth/login, поле access_token.
  2. Где он хранится? В session.headers["Authorization"] одного объекта клиента.
  3. Кто решает, авторизован ли клиент? Фикстура: api без токена, auth_api с токеном.
