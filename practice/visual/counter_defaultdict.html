Counter и defaultdict: что происходит со словарём на каждом шаге

Оба — это обычный dict с одной добавкой: они знают, что делать, когда ключа ещё нет. У обычного dict будет KeyError. defaultdict вызывает фабрику, кладёт результат в словарь и возвращает его. Counter возвращает 0 и ничего не кладёт. Переключай сценарии и смотри на «шкаф».

Что перебираем

Шкаф (словарь): синий — новый ключ, жёлтый — изменён, красный пунктир — ключа нет

Где обычно ошибаются
  • defaultdict(0) вместо defaultdict(int). Нужна функция, которую можно вызвать без аргументов, а не значение. int() возвращает 0, list() — []. С 0 будет TypeError.
  • Проверка if dd[x]: у defaultdict создаёт ключ x. Словарь «сам» растёт, а len(dd) врёт. Проверяй через x in dd.
  • Ждут, что Counter выдаст KeyError на чужом ключе. Он вернёт 0, это удобно, но надо помнить.
  • Counter == Counter сравнивает как словари: порядок не важен. Поэтому Counter(s) == Counter(t) — готовая проверка анаграмм.
