# Тренажёр лайвкодинга

Задачи в стиле собеседований AQA. Тренажёр: `docker compose up -d trainer` → http://localhost:8090.

Правила: таймер 20–30 минут, решение — в `livecoding/task_NN.py`,
запуск — `uv run pytest livecoding/task_01.py -v`.

---

## Пример формата (из реального собеса). Список объявлений

1. Описать тест-кейсы / чек-лист для эндпоинта.
2. Реализовать автотест на Python (requests + pytest) на самый важный кейс, затем — на остальные, сколько успеешь.

```
GET http://localhost:8090/v1/ads/

Параметры:
  commercial: int, 0..100 — процент коммерческих объявлений в выдаче (обязательный)

Ответ 200:
  {
    "count": int,                       — сколько объявлений в ads
    "ads": [
      {
        "ad_id": int,                   — уникальный id
        "type": str,                    — commercial | nonprofit
        "format": str                   — video | picture
      }
    ]
  }

Ошибка: невалидный или отсутствующий commercial → 400 {"error": "bad_request"}
В выдаче всегда 20 объявлений.
```

## Уровень 1. Товар по id

Простой GET, плоский ответ, параметр в пути.

1. Описать тест-кейсы / чек-лист.
2. Написать автотесты (requests + pytest), начиная с самого важного кейса.

```
GET http://localhost:8090/v1/products/{product_id}

product_id: целое число > 0

Ответ 200:
  {
    "id": int,            — совпадает с product_id из запроса
    "name": str,          — название, не пустое
    "price": number,      — цена, больше 0 (число, не строка)
    "in_stock": bool      — есть ли на складе
  }

В каталоге товары с id от 1 до 5.
Нет такого товара → 404 {"error": "not_found"}
Невалидный product_id (0, отрицательный, не число) → 400 {"error": "bad_request"}
```
