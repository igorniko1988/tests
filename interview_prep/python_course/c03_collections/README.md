# C3. Коллекции и их устройство

**Смысл темы.** Коллекции — главный инструмент и в тестах, и на лайвкодинге: ответ API — список
словарей, проверка — сравнение множеств, отчёт — группировка и подсчёт. Мало знать методы: на
собесе спрашивают, **как коллекции устроены внутри** и почему одни операции быстрые, а другие
медленные. Список — массив ссылок подряд, поэтому вставка в начало дорогая. Словарь и множество —
хеш-таблицы, поэтому поиск мгновенный. Плюс модуль `collections`: Counter, defaultdict, deque —
готовые инструменты, которые экономят половину кода.

## Как проходить

Сначала читаешь всю теорию (разделы 1–9). Потом по разделам: `drills.py` → задачи раздела →
«готово C3 …» в чат. Все команды — из папки `interview_prep/python_course/c03_collections`.
В конце — `quiz.py` и вопросы собеса из раздела 9 вслух.

- Упражнения: `uv run python s01_list/drills.py` (сверит и объяснит).
- Задачи: `uv run pytest -k t01`. Условие — в начале файла задачи.
- Quiz: `uv run python quiz.py all` — ответы в ANSWERS до запуска.

`solutions/` — эталон и объяснения к упражнениям, не открывать до решения.
Прогнать тесты на эталоне: `SRC=solutions uv run pytest`.
