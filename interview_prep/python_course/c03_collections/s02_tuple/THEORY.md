# C3 · Раздел 2. tuple и распаковка

[← раздел 1](../s01_list/THEORY.md) · [оглавление урока](../README.md) · [раздел 3 →](../s03_dict/THEORY.md)

**Простыми словами.** Кортеж (`tuple`) — это список, который **нельзя изменить** после
создания: ни добавить, ни удалить, ни заменить элемент. Устроен так же — ряд ссылок подряд, —
только без запаса под рост.

Зачем он нужен, если есть list:
- **как запись** с фиксированным числом полей: `(x, y)`, `("BTC", "1.5")`, `(status, body)`;
- **как ключ словаря** и элемент множества — он хешируемый, если хешируемо всё внутри (C1, раздел 9);
- **чтобы вернуть несколько значений** из функции;
- **как защита**: передал кортеж — никто не добавит в него элемент по ошибке.

```python
point = (10, 20)
point[0]          # 10
point[0] = 5      # TypeError: 'tuple' object does not support item assignment
point.append(30)  # AttributeError: у кортежа нет append
```

### 1. Кортеж делает запятая, а не скобки

```python
a = (1, 2)    # tuple
b = 1, 2      # тоже tuple — скобки не обязательны
c = (1)       # int 1   — скобки здесь просто группировка, как в (1 + 2) * 3
d = (1,)      # tuple из одного элемента
e = 1,        # tuple (1,) — запятая в конце!
f = ()        # пустой tuple — единственный случай, где кортеж делают скобки
```

Запятая в конце строки — частый **баг в тестах**:

```python
expected = {"id": 1},          # ← случайная запятая
assert resp.json() == expected # падает: dict сравнивается с tuple ({'id': 1},)
```

### 2. Неизменяемый — не значит «всё внутри неизменяемо»

Кортеж хранит **ссылки**, и менять нельзя именно их. Объект по ссылке может быть изменяемым
(C1, раздел 3):

```python
t = (1, [2])
t[1].append(3)    # можно: меняем список, ссылка в кортеже та же
print(t)          # (1, [2, 3])
hash(t)           # TypeError: unhashable type: 'list' — внутри изменяемое, ключом быть не может
```

### 3. Распаковка

Справа — любой iterable (кортеж, список, строка, генератор), слева — имена. Количество должно
совпасть:

```python
x, y = (10, 20)
first, second = "ab"             # 'a', 'b'
a, b = b, a                      # обмен значений: справа сначала собирается кортеж (b, a)

x, y = [1, 2, 3]                 # ValueError: too many values to unpack (expected 2)
x, y, z = [1, 2]                 # ValueError: not enough values to unpack (expected 3, got 2)
```

**Звёздочка** собирает «всё остальное» в **список** (даже если справа кортеж):

```python
head, *rest = (1, 2, 3, 4)       # head = 1, rest = [2, 3, 4]
*init, last = "abc"              # init = ['a', 'b'], last = 'c'
first, *_, last = range(5)       # 0 и 4, середина выброшена в _
a, *b = [1]                      # a = 1, b = []  — пустой список, не ошибка
```

Распаковка в цикле — постоянно используется с `dict.items()` и `enumerate`:

```python
for i, (symbol, price) in enumerate([("BTC", "100"), ("ETH", "5")]):
    print(i, symbol, price)
```

**Как работает `a, b = b, a`:**

```
1) справа вычисляется кортеж из ТЕКУЩИХ значений:  (b, a) → (2, 1)
2) кортеж распаковывается по именам слева:        a = 2, b = 1
временная переменная не нужна — её роль играет кортеж
```

### 4. Вернуть несколько значений

Функция всегда возвращает **один** объект. «Несколько значений» — это кортеж, который сразу
распаковали:

```python
def min_max(nums):
    return min(nums), max(nums)    # возвращается кортеж (1, 9)

lo, hi = min_max([4, 1, 9])
```

### 5. namedtuple — кортеж с именами полей

```python
from collections import namedtuple

Order = namedtuple("Order", ["id", "status", "amount"])
o = Order(1, "NEW", "10.5")
o.status          # 'NEW' — читается понятнее, чем o[1]
o[1]              # 'NEW' — индексы тоже работают
o._replace(status="FILLED")   # новый кортеж, старый не меняется
id_, status, amount = o       # распаковка тоже работает
```

Современный вариант с типами — `typing.NamedTuple`. Если поля нужно менять — `dataclass` (C9).

### 6. tuple против list

| | list | tuple |
|---|---|---|
| Изменение | можно | нельзя |
| Хешируемость | нет | да, если всё внутри хешируемо |
| Память | больше — есть запас под рост | меньше, ровно по размеру |
| Смысл | коллекция однотипных элементов, длина меняется | запись: позиция = смысл поля |
| Пример | список ордеров | `(symbol, price)`, ключ `(user_id, date)` |

```python
sys.getsizeof([1, 2, 3])   # 88
sys.getsizeof((1, 2, 3))   # 64
```

---

**Частая ошибка.** `t = ("NEW")` и потом `for s in t:` — ожидали один статус, а идём по буквам
`N`, `E`, `W`. Кортеж из одного элемента — `("NEW",)`. То же с `@pytest.mark.parametrize("x", ("a"))`.

<details><summary>Проверь себя: что выведет?</summary>

```python
a, *b, c = (1, 2)
print(a, b, c, type(b).__name__)
```
`1 [] 2 list`. `a` и `c` забирают крайние, на середину ничего не осталось — `b` пустой.
Звёздочка всегда даёт список, даже когда справа кортеж.
</details>
