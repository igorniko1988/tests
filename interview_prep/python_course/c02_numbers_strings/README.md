# C2. Числа, строки, bool

**Смысл темы.** Числа и строки — то, что автотесты проверяют чаще всего: суммы, цены, статусы,
сообщения, тела ответов. Здесь живут классические вопросы собеса («почему 0.1 + 0.2 ≠ 0.3»,
«как работать с деньгами», «что вернёт `0 or 'x'`») и классические баги тестов: флейки из-за
float, «ложный зелёный» из-за проверки истинности, падения из-за str против bytes.
На нашем стенде все суммы — Decimal и строка в API, поэтому тема нужна каждый день.

## Как проходить

Сначала читаешь всю теорию (разделы 1–9). Потом по разделам: `drills.py` → задачи раздела →
«готово C2 …» в чат. Все команды — из папки `interview_prep/python_course/c02_numbers_strings`.
В конце — `quiz.py` и вопросы собеса из раздела 9 вслух.

## Разделы

| № | Папка | Тема | Задачи |
|---|---|---|---|
| 1 | `s01_int/` | int без переполнения, `/`, `//`, `%` с минусами, `int()` | — |
| 2 | `s02_float/` | Неточность float, сравнение, банковское `round`, nan и inf | — |
| 3 | `s03_decimal/` | Decimal для денег, `quantize`, режимы округления | t01, t02, t03★ |
| 4 | `s04_strings/` | Индексы, срезы, split/join, методы строк | t04 |
| 5 | `s05_fstrings/` | f-строки: точность, ширина, выравнивание, `!r`, `=` | t05 |
| 6 | `s06_bytes/` | str и bytes, UTF-8, encode/decode, битые байты | t06 |
| 7 | `s07_truthy/` | truthy и falsy, `and`/`or` возвращают операнд, bool — это int | t07 |
| 8 | `s08_autotests/` | Где это ломает автотесты: деньги, JSON, approx, проверки истинности | — |
| 9 | `s09_cheatsheet/` | Шпаргалка и вопросы собеса с ответами | вслух |

- Упражнения: `uv run python s03_decimal/drills.py` (сверит и объяснит).
- Задачи: `uv run pytest -k t01`. Условие — в начале файла задачи.
- Quiz: `uv run python quiz.py all` — ответы в ANSWERS до запуска.

`solutions/` — эталон и объяснения к упражнениям, не открывать до решения.
Прогнать тесты на эталоне: `SRC=solutions uv run pytest`.

Зачёт: тесты зелёные + ревью, quiz ≥ 12/15 до запуска, вопросы собеса вслух.
