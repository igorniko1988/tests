**Простыми словами.** `str` — неизменяемая последовательность символов Unicode (C1, раздел 3:
любой «изменяющий» метод возвращает **новую** строку). Со строками работают постоянно: разобрать
ответ API, лог, заголовок, собрать URL или сообщение об ошибке. На собесе — палиндромы,
анаграммы, подсчёт символов, разбор строк лога.

### Индексы и срезы

```
  s = "pytest"
  индекс:    0   1   2   3   4   5
             p   y   t   e   s   t
  с конца:  -6  -5  -4  -3  -2  -1
```

```python
s[0]       # 'p'
s[-1]      # 't' — последний символ
s[1:3]     # 'yt' — с 1 по 3, НЕ включая 3
s[:2]      # 'py' — с начала
s[2:]      # 'test' — до конца
s[::-1]    # 'tsetyp' — разворот (шаг −1)
s[::2]     # 'pts' — каждый второй
s[10]      # IndexError — индекс за пределами
s[10:]     # '' — срез за пределами НЕ падает, просто пустой
```

**Срез всегда создаёт новую строку** (O(k), A0 раздел 3) и **никогда не падает** — лишние
границы обрезаются.

### split и join

```python
"a,b,,c".split(",")         # ['a', 'b', '', 'c'] — режет по каждой запятой
"  a  b ".split()           # ['a', 'b'] — без аргумента: по любым пробелам, пустые выбрасывает
"k=v=w".split("=", 1)       # ['k', 'v=w'] — не больше 1 разреза
"a\nb\n".splitlines()       # ['a', 'b']

"-".join(["2026", "10", "29"])   # '2026-10-29'
", ".join(map(str, [1, 2, 3]))   # '1, 2, 3' — числа сначала в строки
```

`join` — метод **разделителя**, а не списка: `"-".join(parts)`. Он принимает только строки —
`"-".join([1, 2])` даёт `TypeError`.

**Почему join, а не `+=` в цикле.** Строка неизменяема: каждое `s += part` создаёт новую строку
и копирует всё накопленное. На n частях это O(n²) (A0, раздел 4). `join` сначала считает
итоговую длину и копирует каждую часть один раз — O(n).

```python
# плохо
line = ""
for word in words:
    line += word + " "

# хорошо
line = " ".join(words)
```

### Поиск и проверки

```python
"api" in "rapid"              # True — подстрока
"abc".find("z")               # -1 — не нашёл
"abc".index("z")              # ValueError — не нашёл
"abc".count("a")              # 1
"test_login".startswith("test_")   # True
"report.json".endswith((".json", ".xml"))   # True — можно кортеж вариантов
```

### Чистка и замена

```python
"  Bob \n".strip()           # 'Bob' — пробелы и переводы строк по краям
"xxBobxx".strip("x")         # 'Bob' — указанные символы
"Hello".replace("l", "L")    # 'HeLLo'
"Hello".replace("l", "L", 1) # 'HeLlo' — только первая замена
"Hello".lower(), "Hello".upper()
"Straße".casefold()          # 'strasse' — «агрессивный» lower для сравнения без регистра
```

### Проверки символов

```python
"123".isdigit()     # True
"abc1".isalnum()    # True — буквы или цифры
"abc".isalpha()     # True
" ".isspace()       # True
```

Эти методы удобны для «очистить строку от знаков препинания»:
`"".join(ch for ch in s if ch.isalnum())`.

### Сравнение строк

Строки сравниваются **посимвольно по кодам Unicode**: `"Z" < "a"` (90 < 97), `"10" < "9"`
(`'1'` < `'9'`). Поэтому числа, лежащие в строках, сортируются «неправильно» — для сортировки
по числу нужен `key=int`.

---

**Частая ошибка.** Вызвать `s.strip()` / `s.lower()` / `s.replace(...)` и не сохранить результат
(C1, раздел 3). Вторая — `s.split(",")` вместо `s.split()` на строке с двойными пробелами
и получить пустые элементы.

<details><summary>Проверь себя: что выведет?</summary>

```python
log = "2026-10-29 ERROR orders Timeout"
date, level, *rest = log.split()
print(level, rest, "-".join(date.split("-")[::-1]))
```
`ERROR ['orders', 'Timeout'] 29-10-2026`. `*rest` собирает остаток в список; дату развернули
по частям и склеили.
</details>
