# C2 · Раздел 1. Целые числа: int, //, %

[← оглавление урока](../README.md) · [раздел 2 →](../s02_float/THEORY.md)

**Простыми словами.** `int` в Python — целое число **произвольной длины**. В Java или C у целого
числа фиксированный размер (например, 64 бита), и при выходе за предел оно «переполняется» —
превращается в мусор. В Python такого нет: число просто занимает больше памяти.

```python
print(2 ** 64)        # 18446744073709551616
print(2 ** 100)       # 1267650600228229401496703205376 — без ошибок и переполнений
```

Поэтому в Python не нужны отдельные `long`, `BigInteger` и проверки переполнения при сложении
сумм или идентификаторов.

### Три деления: `/`, `//`, `%`

| Оператор | Что делает | `7 ? 2` | `-7 ? 2` |
|---|---|---|---|
| `/` | обычное деление, **всегда float** | `3.5` | `-3.5` |
| `//` | целочисленное деление, **округление вниз** | `3` | `-4` |
| `%` | остаток от деления | `1` | `1` |

**`/` всегда возвращает float**, даже когда делится нацело: `6 / 3` — это `2.0`, а не `2`.
Если нужен int — `//`.

**`//` округляет вниз, к минус бесконечности, а не к нулю.** Для положительных чисел разницы
не видно, а с минусом — видно:

```
 −3,5 на числовой прямой:   … −4 ──●── −3 … 0
                               ↑ вниз      ↑ к нулю
 Python: -7 // 2 = -4       (в C и Java было бы -3)
```

**`%` — остаток, знак которого совпадает со знаком делителя.** Python гарантирует равенство
`a == (a // b) * b + a % b`. Проверим на −7 и 3: `-7 // 3 = -3`, `(-3) * 3 = -9`,
остаток `-7 - (-9) = 2`. Поэтому `-7 % 3 == 2`, а не `-1`.

```python
print(-7 // 3, -7 % 3)    # -3 2
print(divmod(-7, 3))      # (-3, 2) — частное и остаток сразу
```

**Где это используют:** `n % 2 == 0` — проверка чётности (работает и для отрицательных, потому
что остаток всегда 0 или 1); `i % len(items)` — «зациклить» индекс по кругу; `divmod(seconds, 60)`
— минуты и секунды.

### Преобразования: `int()`, `round()`

```python
int("  42 ")        # 42 — пробелы по краям убираются
int("1f", 16)       # 31 — второй аргумент: основание системы счисления
int("101", 2)       # 5
int("3.5")          # ValueError — из строки только целое
int(3.99)           # 3   — дробная часть ОТБРАСЫВАЕТСЯ (к нулю)
int(-3.99)          # -3  — тоже к нулю, а не вниз!
round(3.99)         # 4   — округление (правила — в разделе 2)
```

Обрати внимание: `int(-3.99)` даёт `-3` (к нулю), а `-399 // 100` даёт `-4` (вниз). Это разные
операции.

### bool — это тоже int

`True` и `False` — объекты класса `bool`, а `bool` — **подкласс** `int`. `True` ведёт себя как
`1`, `False` — как `0`:

```python
print(True + True)          # 2
print(sum([True, False, True]))  # 2 — удобно считать, сколько условий выполнено
print(isinstance(True, int))     # True
```

Подробнее о логических значениях — в разделе 7.

---

**Частая ошибка.** Ждать от `-7 // 2` результат `-3` «как в других языках» или использовать
`int(x / y)` вместо `x // y`: для отрицательных они дают разное, а `/` ещё и уводит в float с его
неточностью на больших числах.

<details><summary>Проверь себя: что выведет?</summary>

```python
print(10 // 3, 10 % 3, -10 // 3, -10 % 3)
```
`3 1 -4 2`. −10 / 3 = −3,33… → вниз до −4; остаток: −10 − (−4 · 3) = −10 + 12 = 2.
