# C2 · Раздел 5. f-строки и форматирование

[← раздел 4](../s04_strings/THEORY.md) · [оглавление урока](../README.md) · [раздел 6 →](../s06_bytes/THEORY.md)

**Простыми словами.** f-строка — строка с буквой `f` перед кавычками, внутри которой в `{}`
можно писать **любое выражение Python**. Значение вычисляется и подставляется в текст. После
двоеточия внутри `{}` можно указать **формат**: сколько знаков после запятой, какой ширины поле,
как выровнять.

```python
user, balance = "bob", 1234.5
print(f"{user} has {balance} USDT")           # bob has 1234.5 USDT
print(f"{user.upper()}: {balance * 2}")       # BOB: 2469.0 — выражения прямо внутри
```

Схема одного поля: `{выражение!преобразование:формат}` — обе части после выражения необязательны.

---

### Числа

```python
x = 3.14159
f"{x:.2f}"          # '3.14'      — 2 знака после запятой, с округлением
f"{1234567.891:,.2f}"   # '1,234,567.89' — запятая = разделитель тысяч
f"{7:03d}"          # '007'       — целое, дополнить нулями до ширины 3
f"{0.256:.1%}"      # '25.6%'     — умножить на 100 и добавить %
f"{255:x}", f"{5:b}"    # 'ff', '101' — шестнадцатеричная и двоичная запись
```

`.2f` тоже **округляет банковски**: `f"{2.5:.0f}"` → `'2'`, `f"{3.5:.0f}"` → `'4'`. И с float
наследует его неточность: `f"{2.675:.2f}"` → `'2.67'`. Для денег — форматируй Decimal:
`f"{Decimal('2.675'):.2f}"` → `'2.68'`.

### Ширина и выравнивание

```python
name = "BTC"
f"[{name:<6}]"     # '[BTC   ]'  — влево, ширина 6
f"[{name:>6}]"     # '[   BTC]'  — вправо
f"[{name:^7}]"     # '[  BTC  ]' — по центру
f"[{name:*^7}]"    # '[**BTC**]' — символ-заполнитель перед выравниванием
f"[{42:>6}]"       # '[    42]'  — числа по умолчанию вправо, строки — влево
```

Ширину можно передать переменной: `f"{name:<{width}}"` — вложенные `{}` внутри формата.

**Так строят ровные таблицы** — например, отчёт по тестам:

```python
rows = [("test_login", 0.42), ("test_create_order", 12.5)]
width = max(len(name) for name, _ in rows)
for name, sec in rows:
    print(f"{name:<{width}}  {sec:>6.2f} s")
# test_login           0.42 s
# test_create_order   12.50 s
```

### `!r` и отладка через `=`

```python
s = "hi"
f"{s!r}"           # "'hi'"   — repr: видны кавычки, пробелы и \n
f"{s}"             # 'hi'

qty = 5
f"{qty=}"          # 'qty=5'  — имя и значение сразу (Python 3.8+)
f"{qty * 2 = }"    # 'qty * 2 = 10'
```

`!r` незаменим в сообщениях ассертов: `f"ожидали {expected!r}, получили {actual!r}"` сразу
покажет, что `'5'` — это строка, а `' bob'` — с пробелом.

### Старые способы — узнавать на чужом коде

```python
"%s has %.2f" % (user, balance)          # printf-стиль
"{} has {:.2f}".format(user, balance)    # str.format
```

Логи (`logging`) по-прежнему используют `%`-стиль: `log.info("user %s", user)` — подстановка
выполнится, только если сообщение действительно пишется (раздел про logging — C14).

---

**Частая ошибка.** Кавычки внутри f-строки совпадают с внешними: `f"{d["a"]}"` — до Python 3.12
это SyntaxError. Используй другие кавычки: `f"{d['a']}"`.

<details><summary>Проверь себя: что выведет?</summary>

```python
price, qty = 0.5, 3
print(f"{qty:>3}|{price * qty:.1f}|{'ok':^6}|")
```
`  3|1.5|  ok  |`. Число вправо в поле 3, 1.5 с одним знаком, `'ok'` по центру в поле 6.
</details>
