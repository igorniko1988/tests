# Обязательные задачи C1 и C2 — одной папкой

Минимум практики по C1 и C2 перед контрольной X1: шесть коротких задач, которые чаще всего
встречаются на собесе. Остальные задачи уроков — по желанию, они лежат в папках разделов.

| Файл | Задача | Время | Теория |
|---|---|---|---|
| `c1_t01_fix_default.py` | Починить `tags=[]` по умолчанию | 5 мин | C1, раздел 7 |
| `c1_t04_build_payload.py` | Тело запроса из шаблона, шаблон не портится | 10 мин | C1, раздел 6 |
| `c1_t07_dedupe.py` | Убрать дубли, сохранив порядок (в том числе словари) | 15 мин | C1, раздел 9 |
| `c2_t01_order_total.py` | Сумма ордеров в Decimal с комиссией и округлением | 15 мин | C2, раздел 3 |
| `c2_t04_is_palindrome.py` | Палиндром без учёта регистра и знаков | 10 мин | C2, раздел 4 |
| `c2_t07_coalesce.py` | Первое значение не None — ловушка `x or default` | 5 мин | C2, раздел 7 |

`freeze_helper.py` — готовая функция для `c1_t07_dedupe`, решать её не нужно.

Решение пишешь прямо в файле задачи вместо `raise NotImplementedError`.
Все команды — из папки `interview_prep/python_course/priority_c1_c2`:

- одна задача: `uv run pytest -k c1_t01`
- все шесть: `uv run pytest`

Решил задачу — пиши в чат «готово c1_t01», будет разбор.
