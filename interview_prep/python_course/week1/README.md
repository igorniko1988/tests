# Неделя 1 — задания A1, A2, Q1 и контрольная X1

Все условия на английском, как на лайвкодинге. Решение пишешь прямо в файле задачи
вместо `raise NotImplementedError`. Задачи с ★ — по желанию, остальные обязательны.

| Папка | Что | Обязательные | ★ по желанию |
|---|---|---|---|
| `a1_arrays_strings/` | A1 · Массивы и строки | t01–t06 | t07–t10 |
| `a2_hashing/` | A2 · Хеширование (dict / set) | t01–t06 | t07–t10 |
| `q1_data/` | Q1 · Работа с данными AQA | t02–t05 | t01, t06 |
| `x1_exam/` | X1 · Контрольная недели 1 | всё | — |

**Порядок:** A1 → A2 → Q1 → X1. Контрольную — в конце, на время, без подсказок.

**Проверка** — из папки задания (например `a1_arrays_strings`):
- одна задача: `uv run pytest -k t01`;
- все: `uv run pytest`.

`solutions/` в каждой папке — эталон, не открывать до решения.
Прогнать тесты на эталоне: `SRC=solutions uv run pytest`.

**Правила практики:**
1. Перед кодом напиши 2–3 строки комментария: что на входе и выходе (типы!), крайние случаи.
2. Перед «проверь» запусти `pytest`.
3. «Покажи решение» — только после 20 минут самостоятельной работы; до этого — подсказка.
4. После решения ответь в чат на Follow-up questions из условия.
