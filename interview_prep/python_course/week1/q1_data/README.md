# Q1 · Работа с данными

Задачи, которые на собесах AQA дают вместо LeetCode: обработать ответ API, сравнить
данные, посчитать статистику. Проверяют владение коллекциями и аккуратность с краевыми случаями.

| Файл | Задача | Время | |
|---|---|---|---|
| `t01_endpoint_stats.py` | Статистика по эндпоинтам из access-лога | 20 мин | ★ |
| `t02_json_diff.py` | Diff двух JSON: added / removed / changed | 20 мин | |
| `t03_duplicate_emails.py` | Дубли email без учёта регистра и пробелов | 15 мин | |
| `t04_orders_summary.py` | Сводка ордеров по статусу с суммой в Decimal | 20 мин | |
| `t05_flatten.py` | `{"a": {"b": 1}}` → `{"a.b": 1}` | 20 мин | |
| `t06_validate.py` | Проверка полей и типов ответа без библиотек | 20 мин | ★ |

Проверка (из этой папки): `uv run pytest -k t02`.
