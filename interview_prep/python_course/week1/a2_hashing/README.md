# A2 · Хеширование

Самый частый паттерн собеса. Сигнал в условии: «найти пару», «есть ли дубль»,
«посчитать», «сгруппировать». Вместо повторного поиска по списку (O(n) каждый раз)
запоминаем увиденное в dict или set и проверяем за O(1): O(n²) превращается в O(n).
