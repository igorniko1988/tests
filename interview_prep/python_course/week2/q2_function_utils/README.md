# Q2 · Утилиты на функциях

Куски тестового фреймворка, которые просят на собесах AQA: retry с backoff, шаг теста с логом, отправка пачками, разбор лога, wait_until. Подменяемые clock и sleep для быстрых тестов.

## Как проходить

1. **Теория:** `THEORY.md` — целиком, в конце раздел «Собес» с готовыми ответами.
2. **Задачи** (условия на английском): без ★ — обязательные, ★ — по желанию. Проверка: `uv run pytest -k t01`.

| Файл | Задача | Время | |
|---|---|---|---|
| `t01_retry.py` | retry с экспоненциальной задержкой | 20 мин |  |
| `t02_step.py` | Шаг теста: статус, время, лог | 15 мин |  |
| `t03_filter_log.py` | Фильтр лога по уровню и request_id | 15 мин | ★ |
| `t04_send_in_batches.py` | Отправка пачками с учётом ошибок | 20 мин |  |
| `t05_flatten.py` | Развернуть список любой вложенности | 15 мин | ★ |
| `t06_wait_until.py` | Ожидание условия с таймаутом | 20 мин |  |

Все команды — из этой папки. `solutions/` — эталон, не открывать до решения;
прогнать тесты на эталоне: `SRC=solutions uv run pytest`.
