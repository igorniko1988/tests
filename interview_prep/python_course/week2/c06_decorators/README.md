# C6 · Декораторы

Декоратор как функция над функцией, `@`, `functools.wraps`, декораторы с параметрами, порядок нескольких декораторов, декоратор-класс, декораторы на методах, декораторы pytest.

## Как проходить

1. **Теория:** `THEORY.md` — целиком, в конце раздел «Собес» с готовыми ответами.
2. **Drills:** `drills.py` — 14 «что выведет», обязательные 1–10, «# доп.» — по желанию. Проверка: `uv run python drills.py`.
3. **Задачи** (условия на английском): без ★ — обязательные, ★ — по желанию. Проверка: `uv run pytest -k t01`.

| Файл | Задача | Время | |
|---|---|---|---|
| `t01_timer.py` | timer — время выполнения | 10 мин |  |
| `t02_log_calls.py` | log_calls(log) — аргументы и результат | 15 мин |  |
| `t03_retry.py` | retry(times, exceptions, delay) | 20 мин |  |
| `t04_count_calls.py` | Декоратор-класс со счётчиком | 15 мин |  |
| `t05_ttl_cache.py` | Кэш с временем жизни | 20 мин |  |
| `t06_counted_method.py` | Декоратор-класс, который работает на методах | 25 мин | ★ |

Все команды — из этой папки. `solutions/` — эталон, не открывать до решения;
прогнать тесты на эталоне: `SRC=solutions uv run pytest`.
