# C4 · Функции и области видимости

Функции как объекты, `*args`/`**kwargs`, `*` и `/` в сигнатуре, LEGB, `global`/`nonlocal`,
замыкания, позднее связывание, `lambda`, `functools.partial` и `cache`. База для декораторов (C6)
и фикстур pytest.

## Как проходить

1. **Теория:** `THEORY.md` — целиком, в конце раздел «Собес» с готовыми ответами.
2. **Drills:** `drills.py` — 16 «что выведет», обязательные 1–11, помеченные «# доп.» — по желанию.
   Проверка: `uv run python drills.py`.
3. **Задачи** (условия на английском): обязательные t01–t05, ★ t06 — по желанию.
   Проверка: `uv run pytest -k t01`.

| Файл | Задача | Время | |
|---|---|---|---|
| `t01_make_counter.py` | Счётчик на замыкании | 10 мин | |
| `t02_call_logger.py` | Обёртка с `*args`/`**kwargs` и логом вызовов | 15 мин | |
| `t03_make_multipliers.py` | Починить позднее связывание | 10 мин | |
| `t04_sort_by.py` | Сортировка по нескольким полям, `-` — по убыванию | 20 мин | |
| `t05_build_client.py` | Помощники API через `functools.partial` | 15 мин | |
| `t06_memoize.py` | Свой кэш результатов | 20 мин | ★ |

Все команды — из этой папки. `solutions/` — эталон, не открывать до решения;
прогнать тесты на эталоне: `SRC=solutions uv run pytest`.
