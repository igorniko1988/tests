# A5 · Стек и очередь

**Смысл темы.** Стек — «последним пришёл, первым ушёл» (LIFO): стопка тарелок, кнопка «назад»
в браузере, вызовы функций. Очередь — «первым пришёл, первым ушёл» (FIFO): очередь в кассу,
задачи воркеров, обход в ширину (BFS). Стек нужен, когда надо **вернуться к последнему
незакрытому**: открытая скобка, незаконченная папка в пути, число, для которого ещё не нашли
«следующий больший». Это даёт O(n) там, где в лоб получается O(n²).

**Сигналы в условии:** «скобки», «вложенность», «отменить/назад», «следующий больший/меньший
элемент», «через сколько дней», «выражение», «путь /a/../b», «обработать в порядке поступления».

### 1. Стек и очередь в Python

```python
stack = []
stack.append(1)        # push — O(1)
stack.append(2)
top = stack[-1]        # peek — посмотреть верх, не снимая
x = stack.pop()        # pop — O(1), снимает ПОСЛЕДНИЙ: 2
if not stack: ...      # пустой ли

from collections import deque
queue = deque()
queue.append("a")      # в конец — O(1)
queue.append("b")
first = queue.popleft()  # из начала — O(1): "a"
```

- **Стек — обычный `list`:** `append` и `pop()` работают с концом за O(1).
- **Очередь — `deque`,** не `list`: `list.pop(0)` сдвигает все элементы — O(n) (C3, раздел 6).
- **`pop()` пустого списка — IndexError:** перед `pop`/`stack[-1]` проверяй `if stack`.

### 2. Скобки: стек «незакрытых»

```python
def valid_parentheses(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)                    # открыли — запомнили
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False                    # закрыли не то или нечего закрывать
    return not stack                            # всё ли закрыто
```

```
"([]{})"
(   → [(]
[   → [(, []
]   → снимаем [ — пара ✓   [(]
{   → [(, {]
}   → снимаем { ✓         [(]
)   → снимаем ( ✓         []    → пусто → True
```

- **Почему стек:** закрывающая скобка всегда закрывает **последнюю** открытую — ровно верх стека.
- **Три ошибки, которые ловит алгоритм:** не та пара `(]`, лишняя закрывающая `())`, незакрытая
  `((`. Последнюю ловит `return not stack`.

### 3. Монотонный стек: «следующий больший»

Задача: для каждого дня — через сколько дней станет теплее. В лоб — для каждого дня смотреть
вперёд: O(n²). Стек хранит индексы дней, **для которых ответ ещё не найден**; температуры в нём
убывают сверху вниз.

```python
def daily_temperatures(temps):
    answer = [0] * len(temps)
    stack = []                              # индексы, ждущие более тёплого дня
    for i, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            j = stack.pop()                 # день j дождался тепла
            answer[j] = i - j
        stack.append(i)
    return answer
```

```
temps = [73, 74, 75, 71, 69, 72, 76]
i=0 73: стек [0]
i=1 74: 73 < 74 → ответ[0]=1, стек [1]
i=2 75: ответ[1]=1, стек [2]
i=3 71: стек [2, 3]
i=4 69: стек [2, 3, 4]
i=5 72: 69<72 → ответ[4]=1; 71<72 → ответ[3]=2; стек [2, 5]
i=6 76: ответ[5]=1; ответ[2]=4; стек [6]
итог [1, 1, 4, 2, 1, 1, 0]
```

- **Почему O(n):** каждый индекс один раз кладётся и один раз снимается.
- **Монотонный стек** — стек, где значения идут по возрастанию или убыванию. Сигнал: «следующий
  больший/меньший», «ближайший слева, который…», «гистограмма».

### 4. Стек для вычислений и путей

```python
def eval_rpn(tokens):                      # ["2", "1", "+", "3", "*"] = (2 + 1) * 3
    stack = []
    for tok in tokens:
        if tok in {"+", "-", "*", "/"}:
            b, a = stack.pop(), stack.pop()   # порядок важен: сначала второй операнд
            ...
        else:
            stack.append(int(tok))
    return stack[0]


def simplify_path(path):                   # "/a/./b/../../c/" -> "/c"
    parts = []
    for part in path.split("/"):
        if part == "..":
            if parts:
                parts.pop()                # подняться на уровень вверх
        elif part and part != ".":
            parts.append(part)
    return "/" + "/".join(parts)
```

- **RPN (обратная польская запись):** операнды идут перед оператором, скобки не нужны. Оператор
  берёт два верхних числа и кладёт результат.
- **Деление в RPN-задачах — к нулю:** `int(a / b)`, а не `a // b` (у `//` округление вниз: `-7 // 2 == -4`).
- **Путь:** каждая папка — push, `..` — pop, `.` и пустые части пропускаем.

### 5. Очередь на двух стеках и стек с минимумом

```python
class MyQueue:
    def __init__(self):
        self.inbox, self.outbox = [], []

    def push(self, x):
        self.inbox.append(x)

    def pop(self):
        if not self.outbox:                 # перекладываем только когда outbox пуст
            while self.inbox:
                self.outbox.append(self.inbox.pop())
        return self.outbox.pop()
```

- **Амортизированное O(1):** каждый элемент перекладывается один раз за всю жизнь.
- **Стек с минимумом за O(1):** рядом с каждым элементом храним минимум на момент его добавления —
  `(value, min_so_far)`. При `pop` минимум «откатывается» сам.
- **Зачем такие задачи:** проверяют, понимаешь ли ты амортизацию и инварианты структуры.

**Частые ошибки.**
- `list.pop(0)` для очереди — O(n) на каждую операцию.
- `stack[-1]` / `stack.pop()` на пустом стеке — IndexError; забыли проверку.
- Не проверили, что стек пуст в конце (`"(("` признали правильной).
- В RPN перепутали порядок операндов: `a - b` против `b - a`.
- `//` вместо деления к нулю для отрицательных.

### Собес

- **Чем стек отличается от очереди и как их делать в Python?** Стек — LIFO, `list` с `append` и
  `pop()`, обе O(1). Очередь — FIFO, `collections.deque` с `append` и `popleft()`, O(1). `list` как
  очередь плох: `pop(0)` — O(n).
- **Как проверить скобки?** Стек открытых: на открывающую — push, на закрывающую — pop и сравнить
  пару. Ошибка, если стек пуст или пара не та; в конце стек должен быть пуст. O(n).
- **Что такое монотонный стек?** Стек, в котором значения упорядочены. Используется для «следующего
  большего/меньшего элемента»: каждый элемент выталкивает из стека все меньшие и даёт им ответ.
  O(n), потому что каждый элемент кладётся и снимается один раз.
- **Как сделать очередь на двух стеках?** Входной и выходной стек. `push` — во входной. `pop` —
  из выходного; если он пуст, переложить туда всё из входного. Каждый элемент перекладывается один
  раз, амортизированно O(1).
