# A5 · Стек и очередь

Стек (LIFO) для «вернуться к последнему незакрытому»: скобки, пути, выражения, монотонный стек «следующий больший». Очередь (FIFO) на deque. Структуры с инвариантами: стек с минимумом, очередь на двух стеках.
