# A4 · Скользящее окно

**Смысл темы.** Задачи про **непрерывный кусок** массива или строки («подмассив», «подстрока»,
«k подряд»). В лоб перебирают все куски: O(n²) кусков, и каждый ещё пересчитывают. Окно — это
кусок `[left, right]`, который ползёт по данным: правый край добавляет элемент, левый убирает,
а нужная величина (сумма, частоты символов) **обновляется за O(1)**, а не пересчитывается.
Каждый элемент входит в окно один раз и выходит один раз — O(n).

**Сигналы в условии:** «подряд», «подмассив/подстрока», «самый длинный/короткий кусок, где…»,
«k последовательных», «окно размера k», «за последние N секунд/запросов» (rate limiter — Q3).

---

### 1. Окно фиксированного размера

```python
def max_sum_k(nums, k):
    window = sum(nums[:k])           # первое окно
    best = window
    for right in range(k, len(nums)):
        window += nums[right] - nums[right - k]   # вошёл правый, вышел левый
        best = max(best, window)
    return best
```

```
nums = [2, 1, 5, 1, 3, 2], k = 3

[2  1  5] 1  3  2      sum = 8
 2 [1  5  1] 3  2      8 + 1 - 2 = 7
 2  1 [5  1  3] 2      7 + 3 - 1 = 9   ← max
 2  1  5 [1  3  2]     9 + 2 - 5 = 6
```

- **Ключ — обновление за O(1):** не `sum(nums[i:i+k])` на каждом шаге (это O(k)), а «+ вошедший,
  − вышедший».
- **Итого O(n)** вместо O(n·k).
- **Для строк окно — частоты символов** (`Counter`/dict): вошёл символ — `+1`, вышел — `-1`.

### 2. Окно переменного размера

Правый край идёт вперёд всегда, левый — только когда окно стало «плохим» (нарушило условие).

```python
def longest_unique(s):
    last_seen = {}          # символ -> последний индекс
    left = best = 0
    for right, ch in enumerate(s):
        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1        # сжать окно за повтор
        last_seen[ch] = right
        best = max(best, right - left + 1)
    return best
```

```
s = "abcabcbb"
right=0 a  [a]          len 1
right=1 b  [ab]         len 2
right=2 c  [abc]        len 3  ← best
right=3 a  повтор a → left=1   [bca]
right=4 b  повтор b → left=2   [cab]
...
```

**Общий шаблон:**

```python
left = 0
for right in range(len(data)):
    добавить data[right] в состояние окна
    while окно плохое:
        убрать data[left] из состояния
        left += 1
    обновить ответ по окну [left, right]
```

- **Почему O(n), хотя внутри `while`:** `left` только растёт и всего сдвинется не больше n раз за
  весь алгоритм, а не за каждую итерацию `for`.
- **«Самый длинный хороший»** — ответ обновляем ПОСЛЕ сжатия (окно снова хорошее).
- **«Самый короткий, удовлетворяющий»** — ответ обновляем ВНУТРИ `while`, пока окно ещё
  удовлетворяет, и сжимаем (задача t03).

### 3. Состояние окна

| Задача | Что хранить | Обновление |
|---|---|---|
| сумма k подряд | число `window` | `+= вошёл - вышел` |
| без повторов | dict «символ → последний индекс» или set | добавить / удалить символ |
| перестановка/анаграмма | `Counter` нужных и `Counter` окна | `+1` / `-1`, сравнить |
| ≤ k замен | частоты + максимальная частота в окне | `длина - max_freq <= k` |
| максимум окна | `deque` индексов (монотонная) | выкинуть меньшие справа, устаревшие слева |

---

### 4. Когда окно НЕ работает

- **Отрицательные числа в «сумма ≥ target»:** при сдвиге левого края сумма может вырасти, а не
  упасть — правило «окно плохое → сжимай» ломается. Нужны префиксные суммы + dict (A8, A2 t07).
- **Не непрерывный кусок** («подпоследовательность», «любые элементы») — это не окно.

---

**Частые ошибки.**
- Пересчитывать `sum(window)` на каждом шаге — O(n·k).
- Длина окна `right - left` вместо `right - left + 1`.
- Сдвинуть `left` назад: `left = last_seen[ch] + 1`, когда `last_seen[ch]` уже левее окна —
  нужна проверка `>= left` (или `max`).
- Сравнивать два `Counter` на каждом шаге для алфавита большого размера — лучше счётчик совпадений.
- Окно размера k, а `len(nums) < k` — не обработан крайний случай.

### Собес

- **Что такое скользящее окно и когда его применять?** Непрерывный кусок `[left, right]`, который
  двигается по данным, а состояние (сумма, частоты) обновляется за O(1) при входе и выходе
  элемента. Применяю для задач про подмассивы и подстроки: «k подряд», «самый длинный кусок без
  повторов», «самый короткий с суммой ≥ target». O(n) вместо O(n²).
- **Почему окно переменного размера — O(n), хотя внутри `while`?** Оба указателя только растут:
  `right` проходит n шагов, `left` за всё время — не больше n. Суммарно 2n.
- **Почему не работает с отрицательными числами?** Окно полагается на монотонность: расширение
  увеличивает сумму, сжатие уменьшает. С отрицательными это неверно — используют префиксные суммы.
- **Где окно в AQA?** Rate limiter «не больше N запросов за последние T секунд», скользящие метрики
  (p95 за последние 5 минут), поиск всплеска ошибок в логе.
