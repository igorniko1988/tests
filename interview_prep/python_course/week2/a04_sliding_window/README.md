# A4 · Скользящее окно

Задачи про непрерывный кусок массива или строки: окно фиксированного и переменного размера, состояние окна (сумма, частоты, монотонная deque). O(n²) → O(n).

## Как проходить

1. **Теория:** `THEORY.md` — целиком, в конце раздел «Собес» с готовыми ответами.
2. **Задачи** (условия на английском): без ★ — обязательные, ★ — по желанию. Проверка: `uv run pytest -k t01`.
