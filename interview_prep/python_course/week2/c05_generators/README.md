# C5 · Comprehensions, итераторы, генераторы

Comprehensions, протокол итератора, свой итератор-класс, генераторы и `yield`, одноразовость, генераторные выражения, `yield from` и пайплайны, itertools, yield-фикстуры pytest.

## Как проходить

1. **Теория:** `THEORY.md` — целиком, в конце раздел «Собес» с готовыми ответами.
2. **Drills:** `drills.py` — 16 «что выведет», обязательные 1–11, «# доп.» — по желанию. Проверка: `uv run python drills.py`.
3. **Задачи** (условия на английском): без ★ — обязательные, ★ — по желанию. Проверка: `uv run pytest -k t01`.
