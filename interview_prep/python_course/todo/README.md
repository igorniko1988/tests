## Проверка

- один модуль: `uv run pytest tests/test_c3.py` (или `test_c1_c2.py`, `test_a0.py`, `test_x0.py`);
- одна задача: `uv run pytest tests/test_c3.py -k t03`, для C1/C2 — `uv run pytest -k c1_t04`;
- A0 t01: `uv run python a0/t01_estimate.py`;
- всё сразу: `uv run pytest`.

Тесты те же, что в уроках: если задача лежит здесь, тест урока тоже берёт её отсюда.

Решил — пиши в чат «проверь c3 t03», будет разбор.
