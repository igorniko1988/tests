# Python к собесу AQA

Программа курса (с отметками прогресса): https://claude.ai/artifact/BoyW5f8ooxGvGYaeSqjxkt
Копия страницы: `program.html`.

6 недель, три трека каждый день:
- **C** — ядро Python, 16 уроков (вопросы собеса и «что выведет»);
- **A** — алгоритмы, 14 паттернов по 10 задач;
- **Q** — практика AQA: утилиты, классы, автотесты, ревью.
Плюс контрольная каждую субботу (X1–X5), входная диагностика X0, мок-собесы и итоговый экзамен.

Урок: папка `<код>_<тема>/` — `THEORY.md` (в конце «Собес» с ответами), `quiz.py` (15 «что выведет»),
`tasks/` + `tests/`, `solutions/` (не открывать до решения), `visual/`.
Проверка: `uv run pytest -q -k t03` из папки урока.

Урок засчитан: тесты зелёные и ревью пройдено, quiz ≥ 12/15 до запуска, вопросы собеса вслух без подсказок.
