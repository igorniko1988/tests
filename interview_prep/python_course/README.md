# Python к собесу AQA

Программа курса (с отметками прогресса): https://claude.ai/artifact/BoyW5f8ooxGvGYaeSqjxkt
Копия страницы: `program.html`.

6 недель, три трека каждый день:
- **C** — ядро Python, 16 уроков (вопросы собеса и «что выведет»);
- **A** — алгоритмы, 14 паттернов по 10 задач;
- **Q** — практика AQA: утилиты, классы, автотесты, ревью.
Плюс контрольная каждую субботу (X1–X5), входная диагностика X0, мок-собесы и итоговый экзамен.

Урок: папка `<код>_<тема>/`, внутри — папка на каждый раздел теории `sNN_<тема>/`:
- `THEORY.md` — теория раздела, в конце «Практика к разделу» с командами;
- `drills.py` — упражнения «что выведет»: ответы вписываешь прямо под фрагментами,
  проверка `uv run python sNN_<тема>/drills.py` (сверяет и объясняет, общий запускатель — `drill.py`);
- `tNN_*.py` — задачи, которые относятся к разделу; проверка `uv run pytest -k t03`.

На уровне урока: `README.md` (оглавление), `quiz.py` (15 «что выведет» на весь урок), `tests/`,
`solutions/` (не открывать до решения), `visual/`. Все команды — из папки урока.

Как идём: каждый раздел — **теория → drills → задачи раздела → разбор**, только потом следующий
раздел. Задачи раздела обязательны, без них раздел не закрыт.

Урок засчитан: тесты зелёные и ревью пройдено, quiz ≥ 12/15 до запуска, вопросы собеса вслух без подсказок.
