# C1 · Раздел 8. Как передаются аргументы в функцию

[← раздел 7](../s07_default_arg/THEORY.md) · [оглавление урока](../README.md) · [раздел 9 →](../s09_hashable/THEORY.md)

**Простыми словами.** При вызове функции её параметры становятся новыми **ярлыками на те же
объекты**, что передал вызывающий код. Вызов `change(nums, k)` для параметров `lst, n` — это,
по сути, `lst = nums` и `n = k` внутри функции. А мы уже знаем из раздела 2: присваивание
ничего не копирует.

Отсюда два правила:
- **мутация** объекта внутри функции (`lst.append`, `d["k"] = ...`) **видна снаружи**:
  объект-то один;
- **переприсваивание** параметра (`lst = [0]`, `n += 1` для числа) снаружи **не видно**:
  переклеился только локальный ярлык.

```python
def change(lst, n):
    lst.append(1)   # мутация общего списка — снаружи увидят
    lst = [0]       # переклеили локальный ярлык lst — снаружи не увидят
    n += 1          # int неизменяем: n переклеен на 6, k снаружи остался 5

nums, k = [], 5
change(nums, k)
print(nums, k)      # [1] 5
```

```
 во время вызова, после lst.append(1):

 глобальные:  nums ──┐          k ──▶ 5
                     ├──▶ list [1]
 change():    lst  ──┘          n ──▶ 5
```

**Как это называется.** Не «по значению» и не «по ссылке»:
- если бы было **по значению** (копия, как в C), `append` внутри функции не изменил бы `nums`;
- если бы было **по ссылке** (как `&` в C++), `lst = [0]` изменил бы `nums` снаружи.

Ни то, ни другое не верно. Правильный термин — **передача по ссылке на объект** (pass by
object reference, call by sharing).

**Хороший тон.** Функция, которая меняет переданный объект, должна явно об этом говорить
(как `list.sort()`, которая возвращает `None`). Иначе — работать с копией и возвращать новый
объект (как `sorted()`). Хелперы тестового фреймворка лучше писать во втором стиле: меньше
сюрпризов.

<details><summary>Проверь себя: что выведет?</summary>

```python
def f(d):
    d["x"] = 1
    d = {}
    d["y"] = 2

data = {}
f(data)
print(data)
```
`{'x': 1}`. Первая строка — мутация общего словаря, дальше `d` переклеен на новый словарь,
и `y` попадает уже в него.
</details>
