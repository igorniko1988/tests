# C1 · Раздел 3. Изменяемые и неизменяемые объекты

[← раздел 2](../s02_names/THEORY.md) · [оглавление урока](../README.md) · [раздел 4 →](../s04_plus_vs_iadd/THEORY.md)

**Простыми словами.** Объект называется **изменяемым** (mutable), если его значение можно
поменять «на месте» — не создавая новый объект. **Неизменяемый** (immutable) объект поменять
нельзя вообще: любая операция, которая выглядит как изменение, на самом деле создаёт
**новый** объект.

| Неизменяемые (immutable) | Изменяемые (mutable) |
|---|---|
| `int`, `float`, `complex`, `bool`, `str`, `bytes`, `tuple`, `frozenset`, `None` | `list`, `dict`, `set`, `bytearray`, объекты твоих классов (по умолчанию) |

**Как «меняется» неизменяемое число.** Пятёрка не может стать шестёркой. Строка `x = x + 1`
создаёт **новый** объект `6` и переклеивает на него ярлык `x`:

```python
x = 5
print(id(x))     # 4341114288
x = x + 1
print(id(x))     # 4341114320 — другой id, значит другой объект
```

```
 до:     x ──▶ 5
 после:  x ──▶ 6        (5 никто не менял, ярлык x просто переклеили)
```

**Строки тоже неизменяемы.** Все методы строк возвращают **новую** строку и не трогают исходную:

```python
s = "hello"
s.upper()            # вернула "HELLO", но результат никуда не сохранили
print(s)             # hello
s = s.upper()        # правильно: сохранить результат (переклеить имя)
print(s)             # HELLO

s[0] = "J"           # TypeError: 'str' object does not support item assignment
```

**Методы изменяемых объектов обычно возвращают `None`.** Это сделано специально: так Python
подсказывает «я изменил объект на месте, нового объекта нет».

```python
nums = [3, 1, 2]
result = nums.sort()     # сортирует сам список
print(nums, result)      # [1, 2, 3] None

nums = nums.sort()       # частая ошибка: nums теперь None!
nums = sorted([3, 1, 2]) # sorted() — функция, она возвращает НОВЫЙ список
```

**Кортеж: неизменяем «каркас», а не содержимое.** Кортеж хранит ссылки на объекты, и
неизменяемы именно эти ссылки: нельзя заменить элемент, добавить или удалить. Но если ссылка
ведёт на изменяемый объект, сам этот объект менять можно:

```python
t = (1, [2])
t[1].append(3)       # можно: меняем список, на который ссылается кортеж
print(t)             # (1, [2, 3])
t[1] = [0]           # нельзя: TypeError — это замена ссылки внутри кортежа
```

```
 t ──▶ tuple ( ●1 , ● ) 
                    └──▶ list [2, 3]    ← этот список изменяемый
```

**Зачем вообще нужны неизменяемые объекты.**
- Их безопасно передавать куда угодно: никто не испортит строку или число «у тебя за спиной».
- Только их можно использовать как ключи словаря и элементы множества (раздел 9).
- Python может переиспользовать один объект вместо создания многих (кэш малых чисел, раздел 5).

**Частая ошибка.** `name.strip()` или `s.replace("a", "b")` без присваивания результата —
строка не меняется, и тест проверяет старое значение.

<details><summary>Проверь себя: изменяемый или нет и почему?</summary>

`frozenset` — неизменяемый (это «замороженное» множество). `bytes` — неизменяемый,
`bytearray` — изменяемый. Кортеж `(1, [2])` — сам неизменяемый, но содержит изменяемый список,
поэтому его нельзя положить в `set` (раздел 9).
</details>
