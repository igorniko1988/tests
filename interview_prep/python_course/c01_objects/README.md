# C1. Объекты, имена и ссылки

**Смысл темы.** Это фундамент всего Python. Если понять одну мысль — *переменная это имя,
приклеенное к объекту, а не коробка со значением* — то сами собой объясняются десятки
«странных» вещей: почему список изменился, хотя ты его «не трогал», почему `+=` ведёт себя
по-разному у списка и строки, почему копия не до конца копия и почему аргумент по умолчанию
«помнит» прошлые вызовы. На собесе эта тема даёт половину задач «что выведет», а в автотестах —
классические плавающие падения: «тест зелёный один и красный в общем прогоне».

Визуализатор к уроку: https://claude.ai/artifact/TzYJP1PWSAMPkEiyaZNHLh (`visual/objects_refs.html`).

## Как проходить

Для каждого раздела по порядку:
1. Читаешь `sNN_*/THEORY.md`.
2. Решаешь `sNN_*/drills.py`: вписываешь ответы под фрагментами, потом
   `uv run python sNN_*/drills.py` — скрипт сам сверит и объяснит.
3. Если в папке есть задачи `tNN_*.py` — решаешь, проверка `uv run pytest -k tNN`.
   Задачи раздела обязательны. Пишешь в чат «готово C1 разд. N» — разбор drills и задач,
   только потом следующий раздел.

Все команды — из папки `c01_objects`. В конце урока — `quiz.py` (15 «что выведет» на всё,
`uv run python quiz.py all`) и вопросы собеса из раздела 11 вслух.

Обязательно: drills без пометки «# доп.» и задачи без ★. Помеченное «доп.» и ★ — по желанию, раздел закрыт и без них.
