# A6 · Сортировка и интервалы

**Смысл темы.** Многие задачи становятся простыми, если сначала **отсортировать**: соседние
элементы после сортировки — «похожие», и их можно обработать одним проходом. Особенно это касается
**интервалов** `[start, end]`: встречи, бронирования, окна обслуживания, периоды действия цены.
Сортировка по началу превращает «все пары интервалов» (O(n²)) в «каждый с предыдущим» (O(n log n)).

**Сигналы в условии:** «интервалы/отрезки/встречи», «пересекаются», «слить», «сколько комнат»,
«минимум удалений», «составить наибольшее/наименьшее», «упорядочить по правилу».

---

### 1. Что важно знать о сортировке в Python

- **`sorted(x)` / `x.sort()`** — Timsort, O(n log n), **стабильная** (C3, раздел 7).
- **`key=`** — по чему сортировать: `intervals.sort(key=lambda iv: iv[0])`.
- **Кортежи сортируются поэлементно:** `sorted([[1, 4], [1, 2]])` → `[[1, 2], [1, 4]]`.
- **Сравнение двух элементов «по правилу»** — `functools.cmp_to_key(cmp)`, где `cmp(a, b)` возвращает
  отрицательное/0/положительное (задача largest number).
- **Сортировка подсчётом** — когда значений мало (0, 1, 2): O(n) без сравнений.

### 2. Слияние интервалов

```python
def merge(intervals):
    result = []
    for start, end in sorted(intervals):            # по началу
        if result and start <= result[-1][1]:       # пересекается с последним слитым
            result[-1][1] = max(result[-1][1], end)  # расширяем
        else:
            result.append([start, end])              # новый отдельный интервал
    return result
```

```
[[1,3],[8,10],[2,6],[15,18]] → сортируем → [[1,3],[2,6],[8,10],[15,18]]

[1,3]            result = [[1,3]]
[2,6]  2 <= 3 →  result = [[1,6]]         расширили до max(3, 6)
[8,10] 8 > 6  →  result = [[1,6],[8,10]]
[15,18]       →  result = [[1,6],[8,10],[15,18]]
```

- **Почему достаточно сравнить с последним:** после сортировки по началу новый интервал может
  пересечься только с «хвостом» уже слитых.
- **`max(...)` обязателен:** `[1,10]` и `[2,3]` — второй целиком внутри первого.
- **Касание** (`[1,2]` и `[2,3]`) — пересечение или нет? Уточни на собесе: обычно `<=` — сливаем.

### 3. Встречи: сколько нужно комнат

```python
def min_rooms(meetings):
    starts = sorted(s for s, _ in meetings)
    ends = sorted(e for _, e in meetings)
    rooms = best = 0
    j = 0
    for s in starts:
        while j < len(ends) and ends[j] <= s:   # встреча закончилась — комната освободилась
            rooms -= 1
            j += 1
        rooms += 1
        best = max(best, rooms)
    return best
```

- **Идея «события»:** каждое начало — `+1` комната, каждый конец — `-1`. Ответ — максимум
  одновременно занятых.
- **Альтернатива — куча** (`heapq`) с временами окончания занятых комнат.
- **Хватит ли одной комнаты** — проще: отсортировать и проверить, что каждая встреча начинается
  не раньше конца предыдущей.

### 4. Жадный выбор: минимум удалений

Чтобы оставить максимум непересекающихся интервалов, сортируем **по концу** и берём каждый, который
начинается после конца последнего взятого. Ранний конец оставляет больше места остальным.

```python
def erase_overlap(intervals):
    count, last_end = 0, float("-inf")
    for start, end in sorted(intervals, key=lambda iv: iv[1]):
        if start >= last_end:
            last_end = end          # берём
        else:
            count += 1              # удаляем
    return count
```

- **Жадный алгоритм** — на каждом шаге лучший локальный выбор; здесь он даёт глобальный оптимум.
  Доказательство на собесе: «обмен» — любой оптимальный ответ можно заменить нашим, не ухудшив.

### 5. Сортировка по правилу и сортировка без сравнений

```python
from functools import cmp_to_key

def largest_number(nums):
    parts = [str(n) for n in nums]
    parts.sort(key=cmp_to_key(lambda a, b: (b + a > a + b) - (b + a < a + b)))
    result = "".join(parts)
    return "0" if result[0] == "0" else result     # [0, 0] → "0", а не "00"
```

- **Правило «a раньше b, если a + b > b + a»:** для `"9"` и `"34"` — `"934" > "349"`, значит 9 раньше.
- **Dutch national flag (sort colors):** три указателя `low`, `mid`, `high` — за один проход
  раскладывает 0, 1, 2 на месте.

### 6. Интервалы в AQA

- **Окна обслуживания и расписания:** проверить, что слоты API не пересекаются, слить периоды.
- **Тайм-лайн событий:** по логам начала/конца запросов найти пиковую параллельность (min rooms).
- **Валидация данных:** «периоды действия тарифов не должны перекрываться» — сортировка + проверка
  соседей.

---

**Частые ошибки.**
- Забыть отсортировать перед слиянием.
- `result[-1][1] = end` вместо `max(...)` — вложенный интервал «укорачивает» слитый.
- Не уточнить, считается ли касание `[1,2]`, `[2,3]` пересечением.
- В «минимум удалений» сортировать по началу — жадный выбор по концу.
- largest number на `[0, 0]` вернул `"00"`.

---

### Собес

- **Как слить пересекающиеся интервалы?** Отсортировать по началу, идти по ним и сравнивать с
  последним слитым: если начало ≤ его конца — расширить конец до максимума, иначе начать новый.
  O(n log n) из-за сортировки, проход O(n).
- **Сколько нужно переговорок?** Разделить на события начала и конца, отсортировать; идти по
  началам, освобождая комнаты, у которых конец ≤ текущего начала; ответ — максимум занятых.
  Или куча с концами встреч. O(n log n).
- **Почему в «минимум удалений» сортируют по концу?** Жадно берём интервал, который раньше всех
  заканчивается: он оставляет больше места для остальных. Это даёт максимум непересекающихся.
- **Как сортировать по нестандартному правилу?** `functools.cmp_to_key` с функцией сравнения двух
  элементов, либо подобрать `key`, который это правило выражает.
