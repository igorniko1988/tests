# C7 · Классы и объекты

self, атрибуты класса и объекта и порядок поиска атрибута, изменяемый атрибут класса, @property, @classmethod и @staticmethod, _protected и __private, cached_property, классы в автотестах.

## Как проходить

1. **Теория:** `THEORY.md` — целиком, в конце раздел «Собес» с готовыми ответами.
2. **Drills:** `drills.py` — 14 «что выведет», обязательные 1–10, «# доп.» — по желанию. Проверка: `uv run python drills.py`.
3. **Задачи** (условия на английском): без ★ — обязательные, ★ — по желанию. Проверка: `uv run pytest -k t01`.
