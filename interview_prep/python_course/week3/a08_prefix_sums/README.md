# A8 · Префиксные суммы

Накопленные суммы: сумма отрезка за O(1), префикс + dict для подмассивов с суммой k (работает с отрицательными), первые индексы префиксов, Kadane, разностный массив.

## Как проходить

1. **Теория:** `THEORY.md` — целиком, в конце раздел «Собес» с готовыми ответами.
2. **Задачи** (условия на английском): без ★ — обязательные, ★ — по желанию. Проверка: `uv run pytest -k t01`.
