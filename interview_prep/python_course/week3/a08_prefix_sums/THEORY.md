# A8 · Префиксные суммы

**Смысл темы.** Префиксная сумма `prefix[i]` — сумма первых `i` элементов. Посчитав её один раз
за O(n), сумму **любого** отрезка получаем за O(1): `sum(nums[l:r]) = prefix[r] - prefix[l]`.
Вместе со словарём (A2) это решает задачи «сколько подмассивов с суммой k» за O(n) — там, где
скользящее окно не работает из-за отрицательных чисел (A4). Тот же приём — «разностный массив» —
применяет много обновлений отрезков за O(1) каждое.

**Сигналы в условии:** «сумма отрезка», «много запросов суммы», «подмассив с суммой k / делится на k»,
«равное количество 0 и 1», «индекс, где суммы слева и справа равны», «накопленный итог».

---

### 1. Префикс и сумма отрезка

```python
nums = [3, 1, 4, 1, 5]

prefix = [0]                     # prefix[i] = сумма nums[:i]; prefix[0] = 0 — пустой префикс
for x in nums:
    prefix.append(prefix[-1] + x)
# prefix = [0, 3, 4, 8, 9, 14]

def range_sum(l, r):             # сумма nums[l..r] включительно
    return prefix[r + 1] - prefix[l]

print(range_sum(1, 3))           # 1 + 4 + 1 = 6  →  prefix[4] - prefix[1] = 9 - 3
```

```
индекс:     0   1   2   3   4
nums:       3   1   4   1   5
prefix: 0   3   4   8   9  14
            └─ prefix[l] ─┘        сумма [l..r] = prefix[r+1] − prefix[l]
```

- **Лишний ноль в начале** убирает особый случай «отрезок с начала массива».
- **`itertools.accumulate(nums)`** — то же без нуля: `[3, 4, 8, 9, 14]`.
- **Выгода:** q запросов — O(n + q) вместо O(n · q).
- **Только для неизменяемого массива:** если элементы меняются, нужны другие структуры
  (дерево Фенвика) — на собесе достаточно знать, что такие есть.

### 2. Префикс + dict: подмассивы с суммой k

Сумма отрезка `(i, j]` равна `prefix[j] - prefix[i]`. Хотим `= k`, значит ищем раньше встречавшиеся
префиксы со значением `prefix[j] - k`. Считаем, сколько раз каждый префикс уже встречался:

```python
from collections import defaultdict

def subarray_sum(nums, k):
    seen = defaultdict(int)
    seen[0] = 1                  # пустой префикс: отрезок с самого начала
    prefix = count = 0
    for x in nums:
        prefix += x
        count += seen[prefix - k]   # сколько отрезков заканчиваются здесь с суммой k
        seen[prefix] += 1
    return count
```

```
nums = [1, 2, 3], k = 3
x=1 prefix=1  ищем -2 → 0      seen {0:1, 1:1}
x=2 prefix=3  ищем  0 → 1      [1, 2]          seen {.., 3:1}
x=3 prefix=6  ищем  3 → 1      [3]             итог 2
```

- **Почему работает с отрицательными:** мы ничего не «сдвигаем», а просто ищем нужный префикс.
- **`seen[0] = 1`** — главная деталь: без неё теряются отрезки, начинающиеся с индекса 0.
- **Вариации:** «самый длинный отрезок с суммой k» — храним **первый** индекс каждого префикса;
  «делится на k» — храним `prefix % k`; «равное число 0 и 1» — считаем 0 как −1 и ищем сумму 0.

### 3. Разностный массив: много обновлений отрезков

Задача: к отрезкам `[l, r]` много раз прибавляют значение, в конце нужен итоговый массив.
В лоб — O(длина отрезка) на каждое обновление.

```python
def apply_updates(n, updates):          # updates: [(l, r, delta), ...]
    diff = [0] * (n + 1)
    for l, r, delta in updates:
        diff[l] += delta                # с l начинаем прибавлять
        diff[r + 1] -= delta            # после r перестаём
    result, running = [], 0
    for i in range(n):
        running += diff[i]              # префиксная сумма разностей = итоговые значения
        result.append(running)
    return result
```

- **O(1) на обновление** и O(n) на сборку итога.
- **Где:** бронирования мест (сколько занято в каждый момент), загрузка серверов по времени,
  «сколько активных сессий в каждую минуту» по логам начала и конца.

---

### 4. Связь с другими паттернами

- **Скользящее окно (A4)** — только неотрицательные числа, зато O(1) памяти.
- **Префикс + dict** — любые числа, O(n) памяти.
- **Kadane (максимальная сумма подмассива)** — это «префикс минус минимальный префикс до него»,
  записанный в одну переменную.

### 5. В AQA

- **Отчёты и метрики:** быстрые суммы за произвольные интервалы времени (запросы за период,
  ошибки за окно) — накопленные счётчики. Так устроены counter-метрики Prometheus: `rate` и
  `increase` — разность накопленного значения на концах интервала.
- **Сверка балансов:** накопленный баланс по операциям и проверка «в какой момент ушёл в минус».
- **Нагрузка во времени** по логам начала и конца запросов — разностный массив.

---

**Частые ошибки.**
- Забыть `prefix[0] = 0` / `seen[0] = 1` — теряются отрезки с начала.
- Сдвиг на единицу: `prefix[r] - prefix[l]` вместо `prefix[r + 1] - prefix[l]` для включительного `r`.
- Применять скользящее окно к массиву с отрицательными числами.
- В «самом длинном» перезаписывать индекс префикса — нужен ПЕРВЫЙ.
- Отрицательный остаток в задачах на делимость: в Python `%` уже неотрицательный, в Java/C — нет.

### Собес

- **Что такое префиксная сумма и зачем она?** Массив накопленных сумм: `prefix[i]` — сумма первых
  i элементов. Сумма любого отрезка — разность двух префиксов за O(1), предобработка O(n).
- **Как посчитать число подмассивов с суммой k за O(n)?** Идти с накопленной суммой и словарём
  «префикс → сколько раз встречался», начиная с `{0: 1}`. Для каждой позиции прибавить
  `seen[prefix - k]`. Работает и с отрицательными числами, в отличие от окна.
- **Префиксные суммы или скользящее окно?** Окно — когда числа неотрицательные и важна O(1)
  память. Префикс + dict — для любых чисел.
- **Что такое разностный массив?** Массив изменений: прибавление к отрезку `[l, r]` — это `+d` в `l`
  и `−d` в `r + 1`; префиксная сумма даёт итог. O(1) на обновление.
