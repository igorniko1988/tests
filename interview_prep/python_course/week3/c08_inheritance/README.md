# C8 · Наследование и проектирование

Четыре принципа ООП, наследование и переопределение, super() и __init__, MRO и ромб, абстрактные классы, утиная типизация и Protocol, композиция против наследования, mixin, SOLID на примере фреймворка.

## Как проходить

1. **Теория:** `THEORY.md` — целиком, в конце раздел «Собес» с готовыми ответами.
2. **Drills:** `drills.py` — 14 «что выведет», обязательные 1–10, «# доп.» — по желанию. Проверка: `uv run python drills.py`.
3. **Задачи** (условия на английском): без ★ — обязательные, ★ — по желанию. Проверка: `uv run pytest -k t01`.

| Файл | Задача | Время | |
|---|---|---|---|
| `t01_client_hierarchy.py` | BaseClient и UsersClient | 20 мин |  |
| `t02_predict_mro.py` | Предскажи MRO и вызовы super() | 15 мин |  |
| `t03_abstract_page.py` | Абстрактная BasePage и LoginPage | 20 мин |  |
| `t04_composition.py` | Страница из компонентов | 20 мин |  |
| `t05_refactor_srp.py` | Разделить «божественный» класс | 25 мин |  |
| `t06_logging_mixin.py` | Логирование через mixin | 20 мин | ★ |

Все команды — из этой папки. `solutions/` — эталон, не открывать до решения;
прогнать тесты на эталоне: `SRC=solutions uv run pytest`.
