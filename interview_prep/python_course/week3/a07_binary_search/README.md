# A7 · Бинарный поиск

Деление пополам на отсортированных данных и монотонных условиях: поиск элемента, граница «первый True», bisect, поиск по ответу, повёрнутый массив. O(n) → O(log n).

1. **Теория:** `THEORY.md` — целиком, в конце раздел «Собес» с готовыми ответами.
