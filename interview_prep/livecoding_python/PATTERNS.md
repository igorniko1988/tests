# Как выбрать паттерн: шпаргалка

## Алгоритм на собесе

1. Перескажи условие, спроси про граничные случаи и размер входа.
2. Реши в лоб и назови сложность. Это нормально и даже нужно.
3. Спроси себя: **что в решении в лоб делается лишнего?**
   - ищу одно и то же снова и снова → **хеш (dict / set)**;
   - перебираю все пары в отсортированном → **два указателя**;
   - пересчитываю каждый подотрезок заново → **окно** или **префиксные суммы**;
   - сортирую всё ради k лучших → **куча**;
   - перебираю все значения ответа по порядку → **бинарный поиск по ответу**;
   - считаю одну и ту же подзадачу много раз → **DP**.
4. Пиши код, прогони пример глазами, назови сложность.

## Сигналы в условии → паттерн

| Слова в условии | Паттерн | Структура | Сложность |
|---|---|---|---|
| найти пару, дубль, «встречалось ли», посчитать, сгруппировать | хеш-таблица | `dict`, `set`, `Counter`, `defaultdict` | O(n) |
| отсортированный массив, пара с суммой, палиндром, развернуть, «на месте», O(1) памяти | два указателя (с концов или read/write) | индексы | O(n), O(1) |
| подстрока / подмассив **подряд**, самый длинный или короткий с условием, k подряд | скользящее окно | `dict` / `set` для окна | O(n) |
| сумма подмассива = k, много запросов суммы на отрезке | префиксные суммы | `list` + `dict` | O(n) |
| скобки, вложенность, «отменить последнее», ближайший больший справа | стек | `list` (`append` / `pop`) | O(n) |
| по уровням, кратчайший путь без весов, очередь задач | BFS | `collections.deque` | O(V + E) |
| отсортировано + O(log n), «минимальное X, при котором …» | бинарный поиск | `bisect` или руками | O(log n) |
| интервалы, встречи, пересечения, слить отрезки | сортировка + проход | `sorted(key=...)` | O(n log n) |
| top-k, k-й наибольший, слить k списков, медиана потока | куча | `heapq` | O(n log k) |
| все варианты: подмножества, перестановки, комбинации | backtracking | рекурсия + список-путь | O(2ⁿ) / O(n!) |
| количество способов, минимальная стоимость, «можно ли собрать» | динамическое программирование | `list` / `dict`, `lru_cache` | обычно O(n·m) |
| дерево: глубина, путь, проверить свойство | DFS (рекурсия) | стек вызовов | O(n) |
| сетка, острова, связность, граф | DFS / BFS + visited | `set`, `deque` | O(V + E) |
| связный список: середина, цикл | быстрый и медленный указатель | два указателя | O(n), O(1) |
| кэш, «последний использованный», LRU | хеш + порядок | `OrderedDict` | O(1) на операцию |
| подряд идущие одинаковые, серии | текущее значение + счётчик | две переменные | O(n) |

## Размер входа подсказывает сложность

| n | Что успеет | Значит |
|---|---|---|
| ≤ 20 | O(2ⁿ) | перебор, backtracking |
| ≤ 1 000 | O(n²) | вложенный цикл допустим |
| ≤ 100 000 – 1 000 000 | O(n) или O(n log n) | хеш, указатели, окно, сортировка |
| очень большое, отсортировано | O(log n) | бинарный поиск |

## Структуры Python: что быстро

| Структура | Быстро O(1) | Медленно | Когда брать |
|---|---|---|---|
| `list` | `a[i]`, `append`, `pop()` | `x in a`, `pop(0)`, `insert(0, x)` — O(n) | порядок, индексы, стек |
| `dict` | `d[k]`, `k in d`, запись | — | «по ключу найти значение», частоты |
| `set` | `x in s`, `add` | — | «было ли», уникальность |
| `Counter` | как dict | `most_common(k)` — O(n log k) | частоты одной строкой |
| `defaultdict(list)` | как dict | — | группировка без проверки «есть ли ключ» |
| `deque` | `append`, `appendleft`, `popleft` | `d[i]` в середине | очередь, BFS, окно |
| `heapq` | `heap[0]` (минимум) | `heappush` / `heappop` — O(log n) | top-k, «следующий минимальный» |
| `sorted` + `bisect` | — | сортировка O(n log n), поиск O(log n) | поиск в отсортированном |

## Пять вопросов себе

1. Вход отсортирован или его можно отсортировать? → указатели, бинарный поиск, интервалы.
2. Нужен **непрерывный** кусок? → окно или префиксные суммы.
3. Нужно помнить, что уже видел? → `dict` / `set`.
4. Важен последний добавленный или первый? → стек или очередь.
5. Нужны **все** варианты или **лучший**? → backtracking или DP.
